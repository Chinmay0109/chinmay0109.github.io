# Publish Chinmay's GitHub profile and portfolio

These are two distinct GitHub features: a **profile README** and a **GitHub Pages website**.

## 1. Publish your GitHub profile README

1. Sign in to https://github.com/ as **Chinmay0109**.
2. Create a **public** repository named exactly `Chinmay0109` (matching your username, including capitalization).
3. Add the provided `README.md` file to the repository root. You can use **Add file → Upload files**, then commit.
4. Visit https://github.com/Chinmay0109 to see your profile README.

## 2. Publish the website using GitHub Pages

**Recommended: user site URL `https://chinmay0109.github.io/`**

1. Create a second **public** repository named `chinmay0109.github.io` under your account. GitHub repository names are case-insensitive.
2. Upload `index.html`, `styles.css`, and `script.js` directly to the repository root (not inside a nested folder), then commit.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**; choose `main` and `/(root)`; click **Save**.
5. Wait for GitHub Pages deployment to complete. Visit https://chinmay0109.github.io/.
6. In your GitHub profile settings, add `https://chinmay0109.github.io/` as your website link if desired.

**Alternative:** If you prefer a repository named `portfolio`, publish it via Settings → Pages and use `https://chinmay0109.github.io/portfolio/` instead. This site's relative CSS/JS links work with either option.
